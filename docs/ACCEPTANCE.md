## Required live checklist — outstanding

Use an owner-authorized Gmail session and record Chrome version, account type, window size, zoom, conversation size, cached/network condition and stage timings. Do not commit private data to this repository.

- [ ] Short conversation, newest-only expanded; verify all originals represented once.
- [ ] Long conversation with grouped older history; compare Gmail's visible total and found/loaded count.
- [ ] Cached hidden bodies and true unavailable bodies; inspect placeholders and export flags.
- [ ] Gmail/Outlook mixed history, inline and bottom-posted replies, multiple signature versions.
- [ ] Real file/image attachments versus inline logos; paperclip ownership.
- [ ] Light/dark themes; Workspace and multiple account routes.
- [ ] Browser zoom and window/divider resize; verify **all** internally sized Gmail reading elements stay left of the dock.
- [ ] Compose, pop-out compose, inline reply and Gmail overlays beside the open dock.
- [ ] Keyboard original navigation, links and selecting/copying body text.
- [ ] Close/reopen/refresh, scroll anchoring, navigation and Close during load.
- [ ] Extension update/reload followed by Gmail reload; one launcher and restored layout.
- [ ] Stable conversation produces no immediate stale notice.
- [ ] Controlled new reply triggers notice and appears after Refresh; older delayed rows reconcile without notice.
- [ ] Focused clipboard export with real browser permission handling and fresh source rows.
- [ ] Record cached 22-message and 56-message latency, including actual paint; compare with proposed 1s/2s targets.

Until these checks pass, V1.0 is implemented and packaged for local validation, not certified ready for every Gmail layout.
